载具队长（Vehicle Commander / Crewman）是载具小队的指挥官，负责指挥[载具](../vehicle/README.md)的运作，并在战场中协调载具与步兵的配合。

## 核心职责

* **载具指挥**：担任载具的指挥位，观察战场态势，向驾驶员与炮手传达目标指令。
* **步兵协调**：载具需要与步兵班紧密配合，载具队长负责与步兵队长沟通，提供火力支援与人员运输。
* **载具维护**：组织载具的维修与弹药补给，避免载具因缺乏维护而在战场上白白损失。
* **战场勘察**：载具队长可以下车侦察，为载具寻找安全的目标与行进路线。

## 装备

载具队长使用车组成员（Crewman）套件，套件为精简自卫配置，**不携带任何爆炸物**：

* **主武器**：卡宾枪、冲锋枪或微型冲锋枪（弹药较少，如 2-3 弹匣）。
* **副武器**：手枪 + 匕首。
* **烟雾弹**：2 个烟雾弹。
* **医疗物资**：2 个野战绷带。
* **工具**：工兵铲、望远镜、**车辆维修工具箱**（用于维修载具）。

### 装备示例（USMC 车组成员）

| 装备类型 | 名称 | 数量 |
|---|---|---|
| 主武器 | M4 卡宾枪 | 2 弹匣 |
| 副武器 | M9A1 手枪 | 2 弹匣 |
| 爆炸物 | 无 | - |
| 烟雾弹 | M18 白烟 | 2 枚 |
| 医疗物资 | 野战绷带 | 2 个 |
| 工具 | 工兵铲、望远镜、维修工具箱 | - |

> 步兵战车（IFV）和主战坦克（MBT）的每个载员位置（驾驶员、炮手、车长、装填手）都必须是车组成员才能操作；装甲运兵车（APC）一般也要求由车组成员驾驶。

## 玩法技巧

* 载具是宝贵的团队资源，损失会影响整局战局，切勿随意丢弃或冒险深入。
* 与[补给载具](../vehicle/logistics/README.md)配合，及时为载具补充弹药。
* 善用地形掩护，避免在开阔地带长时间暴露于[反坦克导弹](../bu-shu-wu-jie-shao/anti-tank-missile.md)等反装甲火力之下。
