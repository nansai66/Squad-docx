# 兵种介绍

这里介绍了步兵班中的各个兵种及其职责，理解每个兵种的分工是团队协作的基础。兵种大致分为四类：

* **直接战斗**：正面交火的常规火力单位（步枪手、自动步枪手）。
* **火力支援**：提供特殊火力支援的兵种（掷弹兵、精准射手、轻型反坦克）。
* **专家**：具有特殊战术价值的限制性兵种（机枪手、重型反坦克、战斗工兵）。
* **指挥与辅助**：负责指挥、救护与载具运作（队长、医疗兵、载具队长、飞行员队长）。

## 直接战斗

* [步枪手](bu-qiang-shou.md)：步兵班骨干，携带弹药包为队友补给弹药。
* [自动步枪手](zi-dong-bu-qiang-shou.md)：用大容量弹匣武器提供持续压制火力。

## 火力支援

* [掷弹兵](zhi-dan-bing.md)：用枪挂榴弹发射器提供曲射火力与烟幕支援。
* [精准射手](jing-zhun-she-shou.md)：用精准步枪提供中远程精确火力与侦察。
* [轻型反坦克](qing-xing-fan-tan-ke.md)：用火箭筒打击轻型装甲与载具。

## 专家

* [机枪手](ji-qiang-shou.md)：用通用机枪提供远程重压制火力。
* [重型反坦克](zhong-xing-fan-tan-ke.md)：用重型反坦克火箭摧毁主战坦克等重装甲。
* [战斗工兵](zhan-dou-gong-bing.md)：专精爆破、布雷与快速建造/拆除部署物。

## 指挥与辅助

* [队长](sl.md)：步兵班的指挥官，负责建立 FOB、指挥小队并协调团队进攻与防守。
* [医疗兵](yi-liao-bing.md)：步兵班的救护核心，负责复活与治疗队友，维持小队持续作战能力。
* [载具队长](zai-ju-dui-zhang.md)：载具小队的指挥官，负责载具的运作与步兵协调。
* [飞行员队长](fei-xing-yuan-dui-zhang.md)：空中载具的驾驶员，负责运输步兵与物资、执行空中侦察。
