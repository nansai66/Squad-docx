# 部署物介绍

这里介绍了游戏中的各种战术部署物。部署物通常由[队长](../role/sl.md)或载具小队使用建材建造，需要[补给载具](../vehicle/logistics/README.md)运送建材后部署，是建立前线阵地、对抗装甲目标的关键手段。

部署物分为三类：

* **技术结构**：FOB 的核心设施，电台被摧毁后随之消失（HAB、弹药架、维修站）。
* **防御工事**：用于提供掩体与掩护，电台被摧毁后仍会保留（碉堡、HESCO 墙、铁丝网）。
* **固定武器**：可提供火力支援的固定武器，电台被摧毁后随之消失（反坦克导弹、重机枪、迫击炮）。

## 技术结构

* [重生点（HAB）](spawn-bunker-chong-sheng-dian.md)：为全队提供前线重生位置，是 FOB 的核心。
* [弹药架](ammo-crate-dan-yao-jia.md)：让玩家补给弹药、更换兵种。
* [维修站](repair-station-wei-xiu-zhan.md)：修复并补充载具的弹药与血量。

## 防御工事

* [碉堡](bunker-diao-bao.md)：内置伪装网的固定观察/火力点。
* [HESCO 墙](hesco-wall-hesco-qiang.md)：构筑坚固掩体的巨型沙箱墙。
* [铁丝网](razor-wire-tie-si-wang.md)：阻挡与减速敌军步兵。

## 固定武器

* [反坦克导弹](anti-tank-missile.md)：重型反装甲武器，可对主战坦克等重型装甲造成致命打击。
* [重机枪](hmg-zhong-ji-qiang.md)：持续压制火力，对付步兵与轻型载具。
* [迫击炮](mortar-pai-ji-pao.md)：曲射火力支援，射程约 1250 米。
