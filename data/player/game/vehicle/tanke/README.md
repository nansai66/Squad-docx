# 主战坦克

这里列出了游戏中的所有主战坦克，主战坦克拥有强大的火力与装甲，是地面战斗的核心力量。

* [ZTZ-99A](ztz-99a.md)：中华人民共和国自主研发的第三代主战坦克。
* [T-90A](t-90a.md)：俄罗斯 T-90 主战坦克系列中的重要型号。
* [T-72S](t-72s.md)：苏联 80 年代后期研发的外贸型 T-72 主战坦克的换代型号。
* [T-72B3](t-72b3.md)：俄罗斯 T-72B 主战坦克的改进型号。
* [T-62](t-62.md)：苏联继 T-54/T-55 后研发的新一代主战坦克。
* [M60T](m60t.md)：由以色列军事工业对 M60 巴顿坦克大幅改装升级而成。
* [M1A2](m1a2.md)：M1A1 的第二阶段改进产品。
* [M1A1](m1a1.md)：M1 主战坦克的第一种大规模改良型。
* [Leopard 2A6M CAN](leopard-2a6m-can.md)：德国豹 2A6 主战坦克的加拿大版本。
* [FV4034](fv4034.md)：联合王国陆军与维克斯联合开发的最新型主战坦克。
