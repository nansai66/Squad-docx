# 轮式装甲运兵车

这里列出了游戏中的所有轮式装甲运兵车，它们以高机动性执行步兵运输与火力支援任务。

* [ZSL10](zsl10.md)：中华人民共和国研制的 8×8 轮式装甲输送车。
* [PARS Ⅲ MK19 RWS](pars-mk19-rws.md)：配备 MK19 榴弹发射器遥控武器站的 PARS 系列车族成员。
* [PARS Ⅲ MG3 RWS](pars-mg3-rws.md)：配备 MG3 机枪遥控武器站的 PARS 系列车族成员。
* [PARS Ⅲ M2 RWS](pars-m2-rws.md)：配备 M2 重机枪遥控武器站的 PARS 系列车族成员。
* [M1126 M2HB](m1126-m2hb.md)：具备高机动性、灵活性以及一定防护能力的 8×8 轮式装甲车。
* [BTR-80](btr-80.md)：由 BTR-70 装甲输送车改进而成的轮式装甲输送车。
* [M1126 M240](m1126-m240.md)：具备高机动性、灵活性以及一定防护能力的 8×8 轮式装甲车。
