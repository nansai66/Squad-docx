# 轮式步战车

这里列出了游戏中的所有轮式步战车，它们具备高机动性，可为步兵提供火力支援。

* [ZBL08](zbl08.md)：中华人民共和国自主研制的 8×8 轮式两栖模块化装甲车族。
* [PARS Ⅲ 25mm](pars-25mm.md)：土耳其 FNSS 公司研发的 PARS 系列轮式装甲车的一个型号。
* [LAV 6.0](lav-6.0.md)：加拿大通用动力陆地系统为加拿大武装部队开发的 LAV III 增强版。
* [LAV-25](lav-25.md)：美国 20 世纪 80 年代初期研制装备的轮式步兵战车。
* [BTR-82A](btr-82a.md)：俄罗斯 BTR-80 轮式装甲运兵车的变体。
* [ASLAV](aslav.md)：LAV-25 的一种变体。
