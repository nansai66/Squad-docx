# 履带式装甲运兵车

这里列出了游戏中的所有履带式装甲运兵车，它们具备良好的越野与两栖能力，是步兵运输的重要装备。

* [AAVP-7A1](aavp-7a1.md)：美国 AAV-7A1 两栖突击载具的人员运输车型。
* [FV432](fv432.md)：由 FV420 系列装甲车发展而来，于 1958 年开始研制。
* [M113A3 M2](m113a3-m2.md)：美国陆军基于 M113 系列装甲车改进而来的装甲运兵车。
* [BTR-MDM](btr-mdm.md)：俄罗斯的履带式、机载、多用途、全两栖装甲运兵车。
* [MT-LB PKT](mt-lb-pkt.md)：苏联 MT-LB 型多用途履带式装甲车配备 PKT 机枪的版本。
* [MT-LB VMK](mt-lb-vmk.md)：苏联 MT-LB 型多用途履带式装甲车的一种改进型号。
* [MT-LBM 6MA](mt-lbm-6ma.md)：苏联（俄罗斯）MT-LB 系列多用途履带式装甲车的一种改进型号。
