# 履带式步战车

这里列出了游戏中的所有履带式步战车，它们具备良好的越野能力，可搭载步兵并为其提供火力支援。

* [ZBD05](zbd05.md)：专为两栖作战打造的现代化载具，是中华人民共和国在两栖作战领域的关键装备。
* [ZBD-04A](zbd-04a.md)：ZBD-04 步兵战车的升级版本。
* [MT-LBM 6MB](mt-lbm-6mb.md)：俄罗斯研制的 MT-LB 系列装甲车辆的现代化改进型号。
* [M7A3](m7a3.md)：外形与 M2A3 几乎一致，将“陶”式反坦克导弹换成了目标定位设备。
* [M2A3](m2a3.md)：M2/M3 系列步兵战车的最新改进车型。
* [FV510](fv510.md)：联合王国陆军主要的履带式装甲战斗车辆之一。
* [BMP-3M](bmp-3m.md)：俄罗斯 BMP-3 步兵战车的现代化改进型号。
* [BMP-2M](bmp-2m.md)：基于 BMP-2 推出的现代化升级版本，融入了新型武器系统与电子设备。
* [BMP-2](bmp-2.md)：苏联在 BMP-1 的基础上研制并列装的第二代履带式步兵战车。
* [BMP-1AM](bmp-1am.md)：由 BMP-1 改进而成。
* [BMP-1](bmp-1.md)：苏联研发生产的步兵战车。
* [BMD-4M](bmd-4m.md)：BMD-4 的改进型空降战车。
* [BMD-1M](bmd-1m.md)：俄罗斯研制的一款空降步兵战车，是 BMD-1 的改进型。
* [ACV-15 25mm](acv-15-25mm.md)：土耳其 FNSS 公司开发的一款两栖步兵战车。
