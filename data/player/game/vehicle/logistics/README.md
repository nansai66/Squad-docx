# 补给载具

这里列出了游戏中的所有补给载具，它们负责为前线运送建材与弹药，是建立 FOB 与维持前线作战的保障。

* [ZSD05 Logistics](zbd05.md)：中国军队海上后勤运输的中坚力量。
* [Ural-4320 Logistics](ural-4320.md)：伊朗联军后勤运输的中坚力量，具有多种用途。
* [Ural-375D Logistics](ural-375d.md)：叛乱军队后勤运输的中坚力量，具有多种用途。
* [MT-LB Logistics](mt-lb.md)：20 世纪 70 年代苏联研制装备的一种履带式装甲输送车。
* [MSVS Logistics](msvs.md)：加拿大陆军后勤运输的中坚力量，具有多种用途。
* [M939 Logistics](m939-logistics.md)：美军后勤运输的中坚力量，具有多种用途。
* [M113A3 Logistics](m113a3.md)：M113 系列装甲车的后勤运输型号。
* [KaMaz 5320 Logistics](kamaz-5320.md)：俄罗斯军队后勤运输的中坚力量，具有多种用途。
* [HX60 Logistics](hx60-logistics.md)：联合王国陆军物流运输中主要的补给运输车辆。
* [CTM-131 Logistics](ctm-131.md)：中国军队后勤运输的中坚力量，具有多种用途。
* [BTR-D Logistics](btr-d.md)：俄罗斯空降军的主要后勤补给载具。
* [BMC-185 Logistics](bmc-185.md)：土耳其陆军后勤运输的中坚力量，具有多种用途。
* [AAVP-7A1 Logistics](aavp-7a1.md)：美国海军陆战队主要的两栖后勤载具。
