# 载具介绍

这里介绍了《Squad》中的所有载具及其数据。载具是团队的重要资产，合理使用载具能够大幅提升队伍的作战能力。

## 主战坦克

地面装甲部队的核心突击力量，拥有强大的火力与防护。

* [主战坦克](tanke/README.md)

## 移动火炮系统

装备大口径火炮的装甲突击载具，可对远距离目标实施精确打击。

* [移动火炮系统](mgs/README.md)

## 步战车

搭载步兵并提供火力支援的装甲战斗车辆。

* [轮式步战车](wheeled-ifv/README.md)
* [履带式步战车](tracked-ifv/README.md)

## 装甲运兵车

用于运输步兵的装甲车辆，部分具备两栖能力。

* [轮式装甲运兵车](wheeled-apc/README.md)
* [履带式装甲运兵车](tracked-apc/README.md)

## 侦察车

用于战场侦察与目标标记的高速装甲车辆。

* [轮式侦察车](wheeled-scout-vehicle/README.md)

## 补给载具

为前线运送建材与弹药的后勤车辆，是建立 FOB 的保障。

* [补给载具](logistics/README.md)
